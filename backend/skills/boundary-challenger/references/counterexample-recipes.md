# 反例构造配方与类比失配检查表

目标：用**学科无关**的模式造出「差一点点」的情境。好反例的标准是——
学习者必须真的理解因果结构才能答对，靠背结论答不对。

---

## 一、八种反例构造模式

### 1. 边界值（把量推到端点）
把某个量推到 0、1、极大、极小、负数。
- 模板：「如果 <量> = 0 呢？你刚才那一步还成立吗？」
- 为什么有效：多数结论只在开区间成立，端点常是特例。

### 2. 单位/量纲不一致
把单位换掉，或让两边单位对不上。
- 模板：「如果 <量> 的单位从 <A> 换成 <B>，等式两边还平衡吗？」
- 为什么有效：单位意识是 `boundary_awareness` 最硬的信号。

### 3. 前提抽掉一条
明确列出他的结论依赖的前提，然后抽掉其中一条。
- 模板：「你这套说法依赖 <前提>。如果 <前提> 不成立，结论变成什么？」

### 4. 顺序颠倒
把两步的顺序换掉。
- 模板：「先做 <第二步> 再做 <第一步>，结果一样吗？为什么？」
- 为什么有效：能答对的人知道哪一步破坏了交换律，答不对的人只是记住了流程。

### 5. 特例当通则
拿他结论的一个特例，问他这个特例能不能反过来推出通则。
- 模板：「你举的这个例子刚好满足 <特殊条件>。换个不满足的，还成立吗？」

### 6. 规模放大（n → n+1 / 小 → 大）
- 模板：「只有一个的时候你讲得通。有一百万个的时候，哪个环节先出问题？」
- 为什么有效：暴露「复杂度盲区」，也是工程类概念最真实的失效场景。

### 7. 逆向提问（结论成立 → 前提必成立？）
- 模板：「如果我看到 <结论> 成立，能反推出 <前提> 一定成立吗？」
- 为什么有效：区分充分条件与必要条件，是最常见的一类因果误认。

### 8. 近似情境判对错（最强的一招）
构造一个**只差一个条件**、因而结论恰好翻转的情境，让他判断对错并说理由。
- 模板：「情境：<具体场景，只差一个条件>。按你的说法这里应该是 <结论>。对吗？」
- 注意：你必须自己先知道正确答案（必要时用 `calculate` 验），
  否则你造的是一道没有标准答案的题 —— 那不是抬杠，是捣乱。

## 二、类比失配检查表

先写下类比的映射关系，再逐行检查：

```
类比：<他给的类比>
映射：原物的 <A> ↔ 类比里的 <A'>
      原物的 <B> ↔ 类比里的 <B'>
```

| 检查项 | 问法 | 失配信号 |
|---|---|---|
| 关键属性是否保真 | 「<A> 最关键的性质是 <P>，类比里的 <A'> 也有 <P> 吗？」 | 类比里 <A'> 有 <P>，但原物的 <A> 其实没有（或反之） |
| 是否多出结构 | 「类比里 <A'> 有 <额外性质 Q>，原物那边有对应吗？」 | 类比白白多出一个结构，他会据此推出原物上不存在的结论 |
| 是否丢失结构 | 「原物的 <B> 有 <性质 R>，类比里能看出来吗？」 | 类比丢了承重性质，而那条性质正是他要解释的东西 |
| 关系类型是否一致 | 「类比里是**精确匹配**还是**加权混合**？原物呢？」 | 精确/模糊、离散/连续、可逆/不可逆 不一致 |
| 量级是否可比 | 「类比里数量级差多少？原物里差多少？」 | 类比是小数，原物是天文数字 |
| 动态是否一致 | 「类比里随时间怎么变？原物呢？」 | 静态类比套在动态过程上 |

**检查表的用法**：找出一处失配，就把它变成一个问题交给他 ——
不要直接把失配结论说出来。他自己说出「这个类比在 <X> 上会失效」，
才算 `boundary_awareness` 的证据；你替他说，那一维就是 0。

## 三、语气规范

**可以**：
- 「我不同意，我举个情况你看看。」
- 「按你这么说，那 <推论> 也应该成立咯？我有点怀疑。」
- 「这个我可能理解错了，你帮我看看：<情境>。」（示弱式抬杠，对受挫倾向的人尤其有效）

**禁止**：
- 人格/智力评价：「这么简单都不会」「你想得太浅了」
- 空泛施压：「你确定吗？」「真的假的？」「不会吧？」
- 讽刺与反话：「哦，原来如此，那真是太对了。」
- 连珠炮：一条消息里塞三个情境（他只会答最后一个）
- 权威压制：「书上说了不是这样」——你要给的是情境，不是权威

---

## 四、什么时候收杠

- 他连续两次答不出，或开始自我否定 → **立刻收杠**，交回教练补给（`Return`）。
- 他已经给出一个成立的反例 + 一个失效场景 → 收杠，交回教练裁决闭合。
- 教练要求回到讲解 → 收杠。
- 你造不出自己已知答案的情境 → 收杠。**不知道答案就不要出题**，
  否则会把他对的答案判成错的，那条错误判定会一路污染到掌握度账本。

## 五、记录格式（交给教练的证据）

```
抬杠：<情境一句话>
他的判断：<对/错/含糊> + <他的理由原话>
边界意识：有 / 无（依据：<他是否主动给出适用条件或反例>）
类比失配点：<若检查了类比，写出失配的那一行；没检查写「未涉及」>
```

「他的理由原话」必须是原话，不要转述成你的说法 ——
转述过的证据无法复核，也无法在换 rubric 之后重跑。
