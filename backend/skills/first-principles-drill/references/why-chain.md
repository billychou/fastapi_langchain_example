# Why-chain 操作手册

## 1. 落点判定：怎么分清四种 Atom

对同一个断言，按顺序问三个问题：

- **它是被规定的吗？**（换一个规定，它就变了）→ `definition`
- **它需要被证明吗？** 若不需要、且本领域把它当前提 → `axiom`
- **它能被验吗？**（代个数字、跑个实验、查个数据就能确认）→ `observable`
- 三个都不是 → `derivable`，**继续下探**

注意 `observable` 与 `derivable` 的界限很实用：**能不能当场验**。
「两个 d 维随机向量的点积，方差随 d 线性增长」——代 d=2 和 d=200 各算一次就能看出趋势，
所以它可以作为 `observable` 落地；但严格结论仍要靠推导，
因此如果学习者给的是推导路径而不是验证路径，落点应记 `derivable` 并继续。

## 2. 假可停点清单（识别 + 反问）

| 假可停点 | 长什么样 | 反问 |
|---|---|---|
| 伪定义 | 「这是定义」但里面含推导步骤 | 「定义里为什么会有『所以』？」 |
| 常识 | 「这大家都知道」 | 「大家是怎么知道的？谁验过？」 |
| 出处 | 「教材/论文就是这么写的」 | 「教材是从哪一步推出来的？」 |
| 同义反复 | 「因为它就是这样的」 | 「把这句话说成不含原词的样子。」 |
| 上楼而非打地基 | 用一个更复杂的术语解释当前术语 | 「这个新词又依赖什么？」 |
| 权威 | 「老师说的」 | 「老师会怎么证给你看？」 |
| 归纳不足 | 「我试过几个例子都成立」 | 「试过几个？哪个情况下最容易不成立？」 |
| 类比当证明 | 「就像水流一样，所以……」 | 「类比在哪里会失效？失效时结论还成立吗？」 |

最后两个特别常见，而且**它们不是垃圾证据**：
「试过几个例子」距离 `observable` 只差一个可复现的验法；
类比距离理解只差一个失效点。所以反问的目的是把它**升级成真落点**，而不是判它无效。

## 3. 下探的深度控制

- **上限 5 层**（`PEDAGOGY_WHY_CHAIN_MAX_DEPTH`）。触顶记「落点未知」。
- **宽度恒为 1**：一层只追一条依赖。学习者一句话里含三个断言时，
  挑**最承重的那一条**下探（去掉它，整段解释就塌的那条），其余记为「本轮未下探」。
- 每层之间要**确认落点再走**：先判定他这句是四种里的哪一种，再决定停或继续。
  跳过判定直接问下一层，会让记录里的 depth 与实际理解脱钩。

## 4. 什么时候该主动停止下探

- 落点是 `definition` / `axiom` / `observable` → 正常停止；
- depth 触顶（5）→ 记「未完成」，交回教练切小概念；
- 连续两层回答互相矛盾 → 记「L<n> 起不自洽」，停止；
- 学习者要求直答 → 停止，交回教练走 `escape_hatch` 确认流程；
- 下探已经偏离本轮 `scope`（`Pick` 阶段写下的范围边界）→ 停止，
  记「越界下探，属另一概念」。**范围是硬约束**：越界的下探会把一轮循环拖成两小时，
  而且产出的证据不属于本轮概念，无法记账。

## 5. 缺口要写成「图上的一条边」

答不出时，不要只记「他不理解 X」。要写成：

```
缺口：from = atom:<更基础的命题>  →  to = atom:<他刚才的断言>
缺失关系：entails（前者应能推出后者）
depth = <在第几层断的>
```

写成边，补给才有目标（教练在 `Return` 里补的就是 `from` 那条 Atom），
掌握度账本才有位置（`mastery_ledger` 按 Atom 记账，不按「感觉」记账）。
写不出这条边，说明你自己也还没定位到缺口 —— 这时该做的是再问一层，而不是下结论。

## 6. 记录范例

```
下探：注意力里要除以 √d_k
  L1 ← 「因为要缩放一下」                  落点：vague（要具体化，不计 depth）
  L1'← 「不除的话点积会很大」               落点：derivable（继续）
  L2 ← 「维度越高，点积的方差越大」          落点：observable（代 d=2/d=200 用 calculate 验过）
depth = 2，落点类型 = observable
缺口：无（L1 的 vague 已由 L1' 具体化）
未下探：「softmax 会饱和」这一条本轮没追，属下轮
```

注意 `vague` 的处理：它**不占 depth**，也不计入掌握度，但要先要具体化再继续 ——
在 vague 上面下探，挖出来的全是空气。
