# 报销单据核对

## 步骤

1. **抽取明细**：从用户输入中列出每笔费用（日期、类目、金额、币种）。信息缺失时先追问，缺失项不要按 0 计算。
2. **分类汇总**：按类目（交通 / 住宿 / 餐饮 / 其他）分别求和。**所有算术必须调用 `calculate`**，禁止心算——金额算错是本技能最严重的失败。
3. **标准校验**：读取 `references/policy.md` 中的限额标准，逐类目比较，标出超标项与超标金额。
4. **输出**：
   - 明细表（Markdown 表格）；
   - 各类目小计 + 总计（保留两位小数）；
   - 「合规结论」：全部合规 / 有 N 项超标（列出类目与超出金额）；
   - 「需补充材料」：缺发票号、缺事由、跨月等。

## 约束

- 币种不一致时不要直接相加，先说明需要按汇率换算并请用户提供汇率。
- 不要臆造限额；`policy.md` 未覆盖的类目按「需人工审核」处理。
- 金额只输出数字与两位小数，不要加货币符号以外的装饰。
