# Frontend — Next.js + Ant Design X Chat UI

Next.js 16 + React 19 + Ant Design X chat UI for the FastAPI LangChain backend. Talks to the backend at `http://127.0.0.1:5001/api/chat` over SSE.

## Prerequisites

- Node 20+
- pnpm 10+
- Backend running on `http://127.0.0.1:5001` (see `../backend/README.md` or root `README.md`)

## Scripts

```bash
pnpm install
pnpm dev        # http://localhost:3000  (dev server with HMR)
pnpm build      # production build
pnpm start      # serve the production build
pnpm lint       # biome check
pnpm format     # biome format --write
```

## Architecture

- **`src/app/page.tsx`** — the entire chat UI. A client component built on Ant Design X:
  - `useXChat` (`@ant-design/x-sdk`) — message state, streaming, retry, abort.
  - `useXConversations` — sidebar conversation list.
  - `DeepSeekChatProvider` + `XRequest('http://127.0.0.1:5001/api/chat', { manual: true })` — adapts the backend's OpenAI-style SSE stream into the X message protocol. One provider per conversation key, cached in `providerCaches`.
  - Assistant bubbles render markdown via `@ant-design/x-markdown`'s `XMarkdown`, with streaming animation tied to `status === 'updating'`.
  - `ThinkComponent` is mapped to the `think` markdown tag.
- **`src/app/layout.tsx`** — root layout, wraps everything in `AntdRegistry` for SSR + Ant Design.
- **`src/app/_utils/local.ts`** — locale strings (zh-CN / en-US) used across the UI.
- **`src/x-markdown/demo/_utils.ts`** — `useMarkdownTheme` hook (light/dark class based on Ant Design token) and a `mockFetch` streaming helper for demos.

The backend's SSE event shape (`{"choices":[{"delta":{"content":"..."}}]}`, terminated by `[DONE]`) is parsed by `DeepSeekChatProvider.transformMessage` in `node_modules/@ant-design/x-sdk/es/chat-providers/DeepSeekChatProvider.js`. The frontend code treats `messages` / `isRequesting` / `abort` / `onReload` / `setMessage` as its API surface, not the raw SSE events.

## Configuration

The backend URL is hardcoded in `src/app/page.tsx`:

```ts
new DeepSeekChatProvider({
  request: XRequest('http://127.0.0.1:5001/api/chat', { manual: true, params: {} }),
})
```

Change it there if your backend runs elsewhere. CORS: the backend's `CORS_ORIGINS` must include the frontend origin (default allows `localhost:3000`).
